# ES採点システム（株式会社アワーズ 採用チーム）

書類選考のES（PDF）を、アワーズの「3つのこころ」に基づく6つの評価軸でClaudeが採点し、Googleスプレッドシートに保存します。結果はGASの閲覧アプリ「ESチェッカー」で確認します。AIの点数は判断の補助であり、合否は採用担当者が判断します。
