# 定時採点のスケジュールタスク

Claude のスケジュールタスクで、1時間ごとに採点の要否を確認します。採点を実行するのは次の2つの場合だけで、それ以外の回は何も書き込まずに終わります。

- 閲覧アプリの「評価する」ボタンが押され、採点依頼シートに「待機中」の行がある
- 毎日18時台（定時採点）

判定と依頼の状態更新の手順は、ES採点スキル（`skill/SKILL.md`）の「実行のきっかけ」に書かれています。

## 設定内容

| 項目 | 値 |
| --- | --- |
| 名前 | ES定時採点（アワーズ） |
| 実行時刻 | 毎日 8〜20時、1時間ごと（`CRON_TZ=Asia/Tokyo 0 8-20 * * *`） |
| アカウント | 会社契約のClaudeアカウント |
| 必要な接続 | Google Drive、Google Sheets |
| パソコン | 不要（クラウドで実行） |

## 実行時の指示（プロンプト）

```
ours-es-scoring スキルを「定時実行」として実行してください。
スプレッドシート「ES採点データ」の採点依頼シートを確認し、スキルの「実行のきっかけ」の判定に従ってください。
採点の対象がない場合は、何も書き込まずに「対象なし」とだけ報告して終了してください。
報告には氏名やESの内容を書かず、件数と応募IDだけを書いてください。
```

## 時刻を変えるとき

1. スケジュールタスクの実行時刻を変更する
2. `src/Code.gs` の `AUTO_SCORING`（画面に表示する時刻）と、`skill/SKILL.md` の「18時台」を同じ値に直す
3. 変更をmainに反映する（閲覧アプリは自動で更新される）。スキルは claude.ai で保存し直す
