# 定時採点のスケジュールタスク

Claude のスケジュールタスクで、決まった時刻にES採点スキルを実行します。採点の手順と記録の付け方は、ES採点スキル（`skill/SKILL.md`）に書かれています。

## 設定内容

| 項目 | 値 |
| --- | --- |
| 名前 | ES定時採点（アワーズ） |
| 実行時刻 | 毎日 6:00ごろ（`CRON_TZ=Asia/Tokyo 50 5 * * *`）。業務でClaudeを使わない早朝に実行し、使用量を日中の業務と取り合わないようにする |
| 1回の上限 | 10件（スキルの「設定」で変更） |
| アカウント | 会社契約のClaudeアカウント |
| 必要な接続 | Google Drive、Google Sheets |
| パソコン | 不要（クラウドで実行） |

## 実行時の指示（プロンプト）

```
ours-es-scoring スキルを「定時実行」として実行してください。
未採点のESがない場合は、何も書き込まずに「対象なし」とだけ報告して終了してください。
報告には氏名やESの内容を書かず、件数と応募IDだけを書いてください。
```

## 使用量について

- Claudeの有料プランには、5時間ごとにリセットされる利用上限と、週単位の上限があります
- 採点中のClaudeは、自分の使用量の残りを確認できません。そのため「使用量の何％まで」という指定はできず、1回あたりの件数で調整します
- 1件あたりの使用量は、ダミーのESで試験採点をして、claude.ai の設定画面にある使用量で確認します。その結果から上限件数と時刻を決めます

## 時刻や件数を変えるとき

1. スケジュールタスクの実行時刻を変更する
2. `src/Code.gs` の `AUTO_SCORING`（画面に表示する時刻）を同じ内容に直す
3. 件数は `skill/SKILL.md` の「設定」の上限件数を直す
4. 変更をmainに反映する（閲覧アプリは自動で更新される）。スキルは claude.ai で保存し直す
