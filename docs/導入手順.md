# 導入手順

会社のGoogle Workspaceアカウントと、会社契約のClaudeアカウントで作業してください。

## 0. 着手前に

- 社内AI活用ガイドライン第7章に沿って、着手時に「TASK」へ届け出る（何を・どのデータで・どこで動かすか）
- 第6章の承認が下りるまでは、**ダミーのESだけ**で動作確認する

## 1. スプレッドシートを作り、コードを反映する

1. 会社のGoogleドライブ（採用チームの共有ドライブ推奨）で、新しいスプレッドシートを作成し、名前を「**ES採点データ**」にする
2. `docs/自動デプロイ設定.md` の手順1〜5で、GitHubからGASへコードを反映する
3. スプレッドシートを再読み込みし、メニュー「**ES採点**」→「**初期設定（シートの作成）**」を実行する。初回は承認画面が出るので、自分のアカウントで許可する

7枚のシート（採点結果・根拠詳細・選考区分・評価基準・設問・権限・採点依頼）ができ、評価基準・設問・選考区分の初期値が入ります。何度実行しても、入力済みのデータは上書きされません。

## 2. シートを設定する

- **選考区分**：ESを保存するフォルダを区分ごとに作り、そのURLを「ESフォルダのURL」に貼る。採点を始める区分の「状態」を「受付中」にする
- **権限**：閲覧アプリを使う人のメールアドレスと役割（管理者・評価者・閲覧者）を追加する。初期設定を実行した人は管理者として登録済み
- **共有**：スプレッドシートとESフォルダは、管理者と採点担当者だけに共有する。評価者・閲覧者には共有しない（閲覧アプリ経由で見る）

## 3. 閲覧アプリを公開する

`docs/自動デプロイ設定.md` の手順6で公開し、デプロイIDを GitHub に登録します。表示されたURLを採用チームに共有してください。「権限」シートに登録されていない人がURLを開いても、「権限がありません」と表示されます。

## 4. 採点の準備（Claude）

1. 会社契約のClaudeアカウントで、Google Drive と Google Sheets のコネクタを接続する
2. ES採点スキル（`skill/SKILL.md`）を claude.ai に保存し、スキル内の「スプレッドシートのURL」を記入する
3. `docs/定時採点タスク.md` の内容でスケジュールタスクを作る
4. TASKの承認が下りたら、スキル内の承認欄を「承認済み（日付）」に書き換える

## 5. 動作確認（ダミーのES）

1. 受付中の区分のフォルダに、ダミーのESのPDFを2〜3件入れる
2. 閲覧アプリで「評価する」を押す（1時間以内に採点が始まる）。すぐに試したい場合は、Claudeで新しいチャットを開き「未採点のESを採点して」と依頼してもよい
3. 閲覧アプリの「最新の状態に更新」で結果を確認する
4. 点数のブレを確かめるときは、採点結果と根拠詳細の該当行を削除してから、もう一度採点する

## 運用のヒント

- 評価基準や設問を変えるときは、行を書き換えず新しい名前（例：新卒総合職_v2）で追加し、選考区分シートの「評価基準」を切り替える。切り替えは新しい年度の受付を始める前に行う
- 根拠詳細を手で直したときは、メニュー「ES採点」→「総合点とランクを再計算」でシートの総合点を更新できる（閲覧アプリは常に根拠詳細から計算して表示する）
- 閲覧アプリでPDFが開かない場合は、管理者がスプレッドシートの「PDFリンク」から開く
- 「採点依頼」シートで「処理中」のまま止まっている行は、次の回にClaudeが「エラー」にして採点をやり直す
