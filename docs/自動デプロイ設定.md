# 自動デプロイの設定（GitHub → GAS）

main ブランチに変更が入ると、GitHub Actions が次を自動で行います。

1. 計算ロジックのテスト（失敗したら反映しない）
2. `src/` のコードをGASへ反映（`clasp push`）
3. Webアプリを新しいバージョンで更新（URLは変わらない）

プルリクエストではテストだけを実行します。

> **注意**：反映のたびにGASのコードは `src/` の内容で上書きされます。GASのエディタで直接コードを編集しないでください（次の反映で消えます）。修正は必ずこのリポジトリで行います。

## 最初に1回だけ行う設定

社内AI活用ガイドライン第7章（認証情報の管理）に沿って、認証情報はコードに書かず、GitHub の Secrets に保存します。リポジトリは**非公開（Private）**にしてください。保管方法が会社の指定に合っているかは、TASKに確認してください。

### 1. Apps Script API を有効にする

会社のGoogleアカウントで https://script.google.com/home/usersettings を開き、「Google Apps Script API」が**オン**になっていることを確認します（オフならクリックしてオンにする）。ほかのアプリでGASの自動デプロイを使っている場合は、すでにオンになっています。

### 2. スクリプトIDとデプロイIDを控える

- **スクリプトID**：Apps Script の左の歯車「プロジェクトの設定」→「スクリプト ID」
- **デプロイID**：Webアプリを公開したあと、「デプロイ」→「デプロイを管理」に表示される ID

### 3. clasp の認証情報（`.clasprc.json`）を用意する

**clasp** は、パソコンやGitHubからGASのコードを書き換えるための、Google公式のツールです。GitHubがGASを更新するには、claspに「このGoogleアカウントで操作してよい」という許可（認証情報）を渡す必要があります。その許可が書かれたファイルが `.clasprc.json` です。

**ほかのアプリでパソコンから自動デプロイしている場合**、そのパソコンにすでにこのファイルがあります。

- Mac：Finderで「移動」→「フォルダへ移動」に `~/.clasprc.json` と入力（隠しファイルのため、普段は見えません）
- Windows：エクスプローラーのアドレス欄に `%USERPROFILE%\.clasprc.json` と入力

ファイルがない場合は、Node.js が入っているパソコンのターミナルで次を実行し、会社のGoogleアカウントで許可します（パソコンのClaude Codeに「clasp login を実行して」と頼んでも構いません）。

```
npx @google/clasp@2.4.2 login
```

ファイルをテキストエディタ（メモ帳など）で開き、中身をすべてコピーします。**このファイルはパスワードと同じ扱いです。チャットやメールに貼らず、次の手順で GitHub の Secrets にだけ貼り付けてください。**

### 4. GitHub に Secrets を登録する

https://github.com/AWS-HR/ES/settings/secrets/actions を開き、「New repository secret」で次の3つを登録します（名前は大文字・アンダースコアまで正確に）。

| 名前 | 値 |
| --- | --- |
| `CLASPRC_JSON` | 手順3の `.clasprc.json` の中身 |
| `GAS_SCRIPT_ID` | 手順2のスクリプトID |
| `GAS_DEPLOYMENT_ID` | 手順2のデプロイID |

Secrets が未設定の間は、テストだけが実行され、GASへの反映はスキップされます。

### 5. 最初の反映

「Actions」タブ →「テストとGASへのデプロイ」→「Run workflow」で実行します。GASにコードが入ったら、スプレッドシートを再読み込みし、メニュー「ES採点」→「初期設定（シートの作成）」を実行します。

### 6. Webアプリの公開設定を確認する

「デプロイ」→「デプロイを管理」で、実行ユーザーが**自分**、アクセスできるユーザーが**（組織名）内の全員**になっていることを確認します。以降は、main に変更が入るたびにWebアプリまで自動で更新されます。

## 担当者が交代するとき

`.clasprc.json` は作成した人のGoogleアカウントの認証情報です。退職・異動の前に、後任者が手順3〜4をやり直して `CLASPRC_JSON` を差し替えてください。
