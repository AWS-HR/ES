# 自動デプロイの設定（GitHub → GAS）

main ブランチに変更が入ると、GitHub Actions が次を自動で行います。

1. 計算ロジックのテスト（失敗したら反映しない）
2. `src/` のコードをGASへ反映（`clasp push`）
3. Webアプリを新しいバージョンで更新（URLは変わらない）

プルリクエストではテストだけを実行します。

> **注意**：反映のたびにGASのコードは `src/` の内容で上書きされます。GASのエディタで直接コードを編集しないでください（次の反映で消えます）。修正は必ずこのリポジトリで行います。

## 最初に1回だけ行う設定

社内AI活用ガイドライン第7章（認証情報の管理）に沿って、認証情報はコードに書かず、GitHub の Secrets に保存します。リポジトリは**非公開（Private）**にしてください。保管方法が会社の指定に合っているかは、TASKに確認してください。

### 1. Apps Script API を有効にする

会社のGoogleアカウントで https://script.google.com/home/usersettings を開き、「Google Apps Script API」をオンにします。

### 2. スクリプトIDを控える

1. 「ES採点データ」スプレッドシートを作成し、「拡張機能」→「Apps Script」を開く（中身は空のままでよい）
2. 左の歯車「プロジェクトの設定」→「スクリプト ID」をコピーする

### 3. clasp の認証情報を作る

Node.js が入っているパソコンで、会社のGoogleアカウントを使って次を実行します（Claude Code に頼んでも構いません）。

```
npx @google/clasp@2.4.2 login
```

ブラウザで許可すると、ホームフォルダに `.clasprc.json` ができます。このファイルの中身をすべてコピーします。**このファイルは他人に渡さない・チャットに貼らないでください。**

### 4. GitHub に Secrets を登録する

リポジトリの「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で、次の3つを登録します。

| 名前 | 値 |
| --- | --- |
| `CLASPRC_JSON` | 手順3の `.clasprc.json` の中身 |
| `GAS_SCRIPT_ID` | 手順2のスクリプトID |
| `GAS_DEPLOYMENT_ID` | 手順6で控えるデプロイID（最初は空のままでよい） |

### 5. 最初の反映

「Actions」タブ →「テストとGASへのデプロイ」→「Run workflow」で実行します。GASにコードが入ったら、スプレッドシートを再読み込みし、メニュー「ES採点」→「初期設定（シートの作成）」を実行します。

### 6. Webアプリを公開し、デプロイIDを登録する

1. Apps Script の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 実行ユーザー：**自分**、アクセスできるユーザー：**（組織名）内の全員** →「デプロイ」
3. 「デプロイを管理」で表示される**デプロイID**をコピーし、Secrets の `GAS_DEPLOYMENT_ID` に登録する

以降は、main に変更が入るたびにWebアプリまで自動で更新されます。

## 担当者が交代するとき

`.clasprc.json` は作成した人のGoogleアカウントの認証情報です。退職・異動の前に、後任者が手順3〜4をやり直して `CLASPRC_JSON` を差し替えてください。
